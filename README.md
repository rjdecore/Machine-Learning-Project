# Machine Learning Portfolio

## Repository Objective
A collection of machine-learning projects covering classification, regression, clustering, NLP, recommendation systems, and model deployment.

## Project Areas
- Customer churn and employee attrition
- Healthcare classification
- Crop-yield and laptop-price regression
- Customer segmentation
- Recommendation systems
- NLP classification/similarity
- Classical regression

## Common ML Workflow
**Data preparation → EDA → feature engineering → preprocessing pipeline → model training → evaluation → deployment where implemented**

## Skills Demonstrated
- Scikit-learn
- XGBoost / CatBoost / LightGBM
- Feature preprocessing with pipelines
- Classification and regression
- K-Means clustering
- NLP and TF-IDF
- Flask and Streamlit deployment
- Model persistence

Each project folder documents the specific methodology and implementation supported by its files.

## Primary Tooling
**Python | Pandas | NumPy | Scikit-learn | XGBoost | CatBoost | LightGBM | Flask | Streamlit**
