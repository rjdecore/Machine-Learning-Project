# Sales & Advertising — Simple Linear Regression

## Objective
Model the relationship between sales and advertising expenditure using Simple Linear Regression and evaluate whether a linear model is appropriate.

## Dataset
The project uses monthly Sales and Advertising observations over **36 months**.

## Modeling
- Train/test split
- Simple Linear Regression
- Ordinary Least Squares concepts
- Prediction
- Residual analysis
- RMSE
- R² evaluation
- Overfitting/underfitting discussion
- Linear-regression assumptions

## Documented Results
The existing analysis reports **RMSE = 11.2273** and **R² = 0.5789**, concluding that the linear model is not a strong fit for the dataset and may benefit from a more flexible model.

## Tech Stack
**Python | Pandas | NumPy | Scikit-learn | Matplotlib | Regression Analysis**
